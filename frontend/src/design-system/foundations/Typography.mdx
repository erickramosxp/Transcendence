# Typography

A tipografia do design system é definida por tokens globais no `theme.css`, estilos semânticos em `@layer base` e utilitários Tailwind que podem sobrescrever esses defaults.

## Fundamentos

<div className="typo-card">
  <div className="typo-stack">
    <div><strong>Font size base:</strong> 16px (`--font-size`)</div>
    <div><strong>Weight normal:</strong> 400 (`--font-weight-normal`)</div>
    <div><strong>Weight medium:</strong> 500 (`--font-weight-medium`)</div>
    <div className="typo-note">
      Os elementos HTML já recebem estilos padrão no layer base. Quando necessário, use utilities como `text-sm`, `text-lg`, `font-normal` e `font-medium` para sobrescrever.
    </div>
  </div>
</div>
