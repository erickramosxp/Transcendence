# Módulo: i18n (Internacionalização e Suporte Multilíngue)

O módulo de **i18n** é encarregado de viabilizar a presença global da plataforma Transcendence (Videa). Ele fornece a infraestrutura que permite que todas as telas, modais, formulários, alertas e notificações dinâmicas da rede social sejam traduzidos instantaneamente para múltiplos idiomas sem degradação de performance ou necessidade de recarregamento físico da página.

---

## 1. Estrutura do Pacote
Localizado em `src/i18n/` e estruturado da seguinte forma:
- `locales/`: Subdiretórios contendo os arquivos de tradução estruturados em formato JSON:
  - `pt-BR/`: Traduções em Português do Brasil (Idioma padrão da plataforma).
  - `en-US/`: Traduções em Inglês Americano.
  - `es-ES/`: Traduções em Espanhol Europeu.
- `index.js` ou `i18n.js`: Arquivo central de configuração e inicialização da biblioteca.

---

## 2. Tecnologias Utilizadas
- **`i18next`**: O framework de internacionalização core para Javascript que fornece a API base de gerenciamento, carregamento de recursos e interpolações.
- **`react-i18next`**: A camada de integração específica para React que disponibiliza hooks reativos de alta performance (como `useTranslation`) e componentes declarativos (como `<Trans />`).

---

## 3. Implementação Prática nos Componentes

### A. O Hook `useTranslation`
A forma mais comum de aplicar traduções em componentes React de UI é através do hook `useTranslation`:

```jsx
import { useTranslation } from 'react-i18next';

const MyComponent = () => {
  const { t } = useTranslation('feed'); // Define o namespace 'feed'
  
  return (
    <button className="btn-primary">
      {t('createPostButton')}
    </button>
  );
};
```

### B. Namespaces Otimizados (Lazy Loading de Traduções)
Para evitar o carregamento desnecessário de dicionários gigantescos de tradução na inicialização do app (o que atrasaria o First Contentful Paint - FCP), as strings estão divididas em **namespaces** (arquivos JSON separados):
- `auth.json`: Login, registro e formulários de cadastro.
- `chat.json`: Interface de salas, mensagens, replies e logs de participantes.
- `feed.json`: Posts, comentários, curtidas e modais de mídias.
- `friends.json`: Solicitações de amizade, status online e contadores.
- `settings.json`: Escolha de tema, idioma e dados da conta.

---

## 4. Recursos Avançados Utilizados

1. **Interpolação de Valores Dinâmicos**:
   - Permite injetar variáveis em tempo de execução no meio de strings traduzidas, preservando a sintaxe regional correta da frase:
     - Dicionário JSON: `"welcomeMessage": "Olá, {{name}}! Bem-vindo de volta."`
     - Componente: `t('welcomeMessage', { name: user.name })`
2. **Pluralização Inteligente**:
   - Gerencia de forma reativa a tradução de palavras que mudam conforme contadores de saldo (ex: likes, comentários, amigos):
     - Dicionário JSON:
       ```json
       "likeCount_one": "{{count}} curtida",
       "likeCount_other": "{{count}} curtidas"
       ```
     - Componente: `t('likeCount', { count: post.likeCount })`
3. **Mapeamento de Fallback**:
   - Caso uma chave de tradução específica esteja ausente nos arquivos JSON do idioma espanhol ou inglês, o sistema recorre de forma transparente ao dicionário de fallback padrão em **Português (`pt-BR`)**, evitando que a interface exiba chaves brutas de código (ex: `feed.createPostButton`).
